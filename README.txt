Terminality

A Java, text-based dungeon crawler game.
----------------------------------------------------------------------------------------------------

Installation:

- Install Java 17+.
- Clone/download the project (https://github.com/AV13RY/terminality)
- In project directory, run:
	- MAC:    ./gradlew run
	- WINDOWS: gradlew.bat run
----------------------------------------------------------------------------------------------------

Program load:
- Click the input area along the bottom of the application.
- Type command & press enter.

- Flow: "help" → "start"

Game start:
- Flow: "name Jack" → "class Mage" → "proceed"

Church area:
- Flow: "choose 1" → "proceed"

In dungeon:
- Navigate: move {direction}
- Combat: attack
- Open Chest: open {number}
- Other: inventory, map, look, use {number} , equip {number}
